# lint-kit-fastapi

FastAPI rules ruff does not have, as a flake8 plugin (FAP001-017), and `lint-kit-structure`,
which fails a branch that makes its Python more complex or more duplicated than its base
([docs](https://github.com/shayshahal/lint-kit/blob/main/docs/structure.md)). Part of
[lint-kit](https://github.com/shayshahal/lint-kit); see its README for settings.
